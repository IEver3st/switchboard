# Clips five-column visual contract

- Surface and job: the Capture clip library should make recent recordings easy to scan, open, favorite, share, and organize.
- Visual authority: the user's second attached image owns clip scale, card composition, metadata hierarchy, and action placement. Switchboard's `DESIGN.md` owns product materials and control semantics.
- First viewport: large 16:9 clip previews dominate. Recorder status and library controls remain visible above them.
- Hierarchy and density: preview, clip title, game or auto-capture context, relative time, then actions. The wide library uses exactly five columns.
- Type roles: compact uppercase game and time labels, stronger clip title, tabular duration.
- Color and material: restrained Switchboard neutrals, one bordered composite clip surface, no gradients, glow, or glass.
- Control grammar: duration overlays the preview; favorite sits on the preview; share and overflow actions live in the footer.
- Signature: five wide media tiles align edge-to-edge with full-bleed previews and an equipment-like metadata rail.
- Anti-reference: the previous auto-fill grid that produced eight undersized clips on wide displays.
- Critical states: hover, keyboard focus, selected montage clips, loading thumbnails, missing thumbnails, filtered empty state, and reduced motion.
- Responsive constraints: five columns at 1080 x 720, 1420 x 900, and 1920 x 1080 without page-level horizontal overflow; dedicated share collapses into the overflow menu at compact widths.
