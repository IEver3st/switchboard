# Device workbench cleanup

- Surface/job: adjust an individual device while keeping its physical identity central.
- Authority: the user's screenshot and no-scroll brief; DESIGN.md and existing device assets/controls.
- First viewport: centered product render dominates; identity, connection, battery, sensitivity, assignments, memory and routine lighting remain visible.
- Composition: quiet control columns flank the mouse; button assignments sit beneath its render. Lighting zones open in a focused popover.
- Type/material: existing Inter hierarchy, tabular readouts, graphite canvas, violet selected/focus states; spacing instead of section rules.
- Control grammar: retain existing typed controls and canonical snapshot writes. Use existing Radix popovers for zones and color editing.
- Signature: authentic hardware silhouette, linked physical button highlights, restrained equipment controls.
- Avoid: long vertical settings forms, intersecting leader lines, oversized zone grids and clipped artwork.
- States: connected, disconnected/unavailable, onboard-disabled, lighting off, effect-specific controls, popovers, focus and reduced motion.
- Sizes: 1080 x 720, 1420 x 900, 1920 x 1080. Reflow below supported desktop width and at zoom rather than clipping controls.
