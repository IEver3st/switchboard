# Mouse device detail visual contract

- Surface and job: G502 X Plus detail workbench; understand the physical controls and tune the active hardware profile without leaving the page.
- Visual authority: the supplied brief, `DESIGN.md`, the incumbent native mouse workbench, and the existing G502 product renders and callout geometry.
- First viewport: the product render and bidirectional button callouts dominate; Sensitivity is the strongest configuration instrument immediately below; compact battery telemetry remains in the header.
- Hierarchy and density: render and assignments first, DPI/report rate second, onboard memory and lighting third. Dense desktop-tool spacing with no card grid or nested settings boxes.
- Type roles: 20px device title, 14px section titles, 11px body/controls, 9-10px supporting metadata, tabular numerals for DPI, Hz, percentages, and hex values.
- Color and material: ink background, graphite interactive controls, steel hairlines, baby-blue only for active interaction/focus, and the selected lighting color only in truthful lighting previews.
- Control grammar: Slider for continuous values, compact ToggleGroup for presets and report rate, Switch for enablement, Select for effects and relevant profiles, Popover for focused editing, Command for searchable assignments, ContextMenu for preset edit/delete.
- Signature: physical mouse control, connector, callout, and assignment behave as one linked interactive target; draft lighting color is reflected on the real render immediately.
- Anti-reference: a beautiful render stacked above generic full-width form rows, equal-weight cards, oversized pills, or controls that imply unsupported hardware behavior.
- Critical states: disconnected/unwritable, onboard versus software profile, lighting off, unsupported effect controls, selected preset, pending draft color, assignment search empty, focus, hover, and narrow-window reflow.
- Responsive constraints: no page-level horizontal overflow at 1080x720, full balanced composition at 1420x900, and controlled maximum widths at 1920x1080. Critical device telemetry and primary DPI controls remain reachable without mandatory horizontal scrolling.
