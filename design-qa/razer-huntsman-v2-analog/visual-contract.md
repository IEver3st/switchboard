# Huntsman V2 Analog workbench visual contract

- **Surface and job:** Devices > Huntsman V2 Analog. Daily control of the active onboard profile, gaming input behavior, and firmware lighting without opening Synapse.
- **Visual authority:** Switchboard's Logitech mouse workbench owns product grammar and density. The supplied Synapse screenshots own feature grouping and control semantics, not styling.
- **First viewport:** The real keyboard render, connection/control status, active profile, Gaming Mode, Rapid Trigger, Snap Tap, and lighting presets remain visible at 1420 x 900. Diagnostics and unsupported analog remapping recede.
- **Hierarchy and density:** One continuous hardware stage followed by a compact two-column control desk. Profile and input state are primary, lighting is secondary, firmware/readback metadata is tertiary.
- **Type roles:** Existing Switchboard title and section roles; compact uppercase metadata; tabular numerals for millimetres, brightness, and polling rate.
- **Color and material:** Existing neutral console surfaces and hairline separators. Cyan is reserved for selection/focus; green and amber communicate verified device state and unavailable ownership. No chroma decoration, gradients, glow, or floating cards.
- **Control grammar:** Exposed profile choices for a small slot count, switches for real booleans, a millimetre slider for Rapid Trigger sensitivity, preset effect buttons plus contextual color/brightness controls, and inline readback status.
- **Signature:** A compact keyboard silhouette/readout stage flows directly into a profile-and-mode rail, making the physical device and active onboard state read as one instrument.
- **Anti-reference:** Avoid the current sparse disclaimer list, equal-weight card grid, oversized empty stage, or controls that only mutate renderer state.
- **Critical states:** Connected, disconnected, HID unavailable, Synapse-owned Snap Tap, command pending, command rejected, confirmed readback, disabled lighting, keyboard focus, and reduced motion.
- **Responsive constraints:** No page-level horizontal overflow at 1080 x 720. Reflow the control desk below 1180 px; preserve critical status and routine controls before mandatory scrolling. Also inspect 1420 x 900 and 1920 x 1080.
