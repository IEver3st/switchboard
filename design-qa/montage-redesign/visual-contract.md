# Montage editor

- Job: assemble, scrub, audition and export an ordered clip sequence with local music.
- Authority: Manuel's annotated screenshots and DESIGN.md. Preserve the media-first graphite workspace.
- First viewport: bounded preview, permanent play/pause and time readout, complete video sequence and actionable music lane. Header holds name, save state and output actions.
- Hierarchy: preview leads; transport and timeline form one editing desk; source details recede into inspector. Compact Inter labels, tabular timecodes, readable 10–12px supporting text.
- Material: existing flat graphite tokens; violet selection/playhead and Media music identity; no decorative cards, gradients or fabricated waveform.
- Controls: fit-relative zoom, draggable/keyboard playhead, semantic playback and import buttons, existing typed import/save/export operations. Music settings are directly reachable from the track.
- Signature: proportionate source thumbnails, continuous ruler/playhead, music aligned beneath the sequence.
- Avoid: oversized source forcing editing controls out of view, hover-only playback, absolute default zoom, tiny metadata ledger.
- States: ready/loading/error preview; empty/importing/failed/muted music; selected/missing clips; save failure; fit/manual zoom; keyboard focus and reduced motion.
- Sizes: native Electron 1080x720, 1420x900, 1920x1080. No page overflow; horizontal timeline scrolling only after deliberate zoom.
