Switchboard 0.9.13 improves capture-only use, clip management, and diagnostics.

- Capture-only setups open directly into the clip library with a compact title bar and an icon-only Settings control.
- Select clips independently of montage creation. Shift-click selects a range; bulk actions can favorite, unfavorite, or move clips to the Recycle Bin. Deletion warns about saved-project references and reports individual failures.
- Missing media stays in the library with Retry, Locate file, and Remove from library actions.
- Keep project saves editing projects beyond the three-hour temporary-draft lifetime.
- Library layout and sorting are saved. Search, filters, and scroll position survive navigation to Settings and back.
- Replay cache can use a separate folder. Storage checks correctly reject full or unavailable volumes.
- Generated clip titles show the game and capture time. Custom names are preserved.
- Diagnostics has a cleaner layout and a new history dropdown with full duration labels and keyboard controls.

GPU memory investigation remains open; this release does not claim a GPU-memory fix. Live drive-disconnect and long-running capture behavior remain separate from automated validation. The Windows installer is unsigned.
