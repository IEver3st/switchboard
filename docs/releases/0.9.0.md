Switchboard 0.9.0 adds saved setup scenes, an optional quick-controls panel, and temporary status lighting for supported devices.

- Save and restore device, audio, and replay settings, with optional application matching.
- Capture audio from the selected game or window process.
- Edit clips with expanded video controls, audio inspection, layouts, and preview improvements.
- Improve audio configuration, device recovery, and rejected-control handling.
- Improve clip-library scrolling and G502 lighting behavior.

The Windows installer is unsigned unless signing credentials are configured. Virtual audio endpoints still require a trusted driver. Physical lighting, global shortcut behavior, game-only recording separation, and installed-update acceptance were not revalidated for this release.
