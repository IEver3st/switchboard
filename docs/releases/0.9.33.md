Switchboard 0.9.33 removes the audio system. Switchboard now focuses on clipping, with hardware control for supported devices.

- Removed the Audio page, Audio settings, the mixer, ChatMix, app routing, EQ, microphone processing and noise removal, spatial audio, and the audio driver setup. The audio engine no longer ships or runs.
- Clips still record separate Game, Chat and Microphone tracks. Each track now records straight from the Windows device you choose in Capture settings, or from the Windows default device when set to Automatic.
- Scenes now cover devices and Instant Replay. Quick controls keep Capture, Frame and App, and their quick actions are Scenes and Save replay.
- Saved audio settings from earlier versions are dropped on first launch. Capture, clips, devices and other settings stay.

If Windows sound output or input still points at a VB-Audio cable or another endpoint that only the old audio engine used, switch it back to your headphones or microphone in Windows sound settings. Switchboard no longer routes those devices.

Local validation covers 462 JavaScript tests, the Capture.Host test suite, type, source and structure checks, and app and Capture.Host builds. Device discovery was checked against real Windows endpoints. The changed screens and a real clip recording have not yet been checked in the packaged app.
