Switchboard 0.9.12 reduces background media work and replay overhead.

- Library indexing and thumbnail generation pause between jobs while the interface is in the tray and resume when reopened. Replay recording and saves continue.
- Replay maintenance reads each stream inventory once, reducing repeated filesystem work.
- Software encoding and encoder probes use bounded worker pools. Video and audio conversion also use smaller thread pools.
- A timeout in an optional encoder probe no longer discards working encoders and restarts the entire capture setup.
- Intel Quick Sync capture receives the input format its encoder supports.
- Clip saves, edits and deletions made during a paused library scan are preserved when scanning resumes.

Validation included native capture tests, software replay cadence and synchronization checks, JavaScript tests, type checks and production builds. A synthetic four-logical-CPU encoding comparison reduced peak private memory from 455 to 358 MiB; encoding took longer but remained faster than the 60 fps source. An isolated, engines-off native idle check passed at approximately 258 MiB in tray mode.

The reported Windows slowdown on an RTX 3090 / Core i9-13900K has not been reproduced on that hardware. Intel capture, NVIDIA gameplay behavior and long-running resource use still need physical validation. The Windows installer is unsigned.
