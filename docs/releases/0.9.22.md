Switchboard 0.9.22 refreshes Devices, Audio, Capture, Settings, and first-run setup while retaining the recent Discord recording and Quick Controls fixes.

- Browse devices in the new hardware view and find settings through grouped navigation and search.
- Keep clip-edit and montage projects, manage selections, and recover media from unavailable folders. Confirmed file deletions still disappear from the library.
- Install, update, roll back, and remove signed community device modules from public GitHub repositories.
- Choose whether to start minimized or move to the tray when a game launches.
- Reduce repeated state updates, device enumeration, and replay-folder scanning.
- Keep the new onboarding backdrop within the idle memory budget by drawing its artwork once per resize.
- Apply silent updates with a bounded shutdown wait and reduced installer resource priority.

The experimental Audio workspace, available in developer mode, can use the standard free VB-CABLE endpoint for separate Game, Chat, and Media app mixing on supported Windows versions. One-cable mode supports personal and clip mixes; separate virtual microphone and stream outputs still require the Switchboard audio driver. Restart an app if Windows has not applied its new route. Existing recording preferences are preserved.

Validation covers JavaScript and native-host tests, hidden Electron checks at 1080 x 720, 1420 x 900, and 1920 x 1080, live VB-CABLE source isolation and route restoration, killed-host recovery, module and audio persistence, and installer/updater checks. Physical disconnect/reconnect, long-running soak, live Discord-call recording, and an installed update/relaunch cycle remain separate acceptance checks.

The isolated, hidden Electron idle check passed with 60-second medians of 328.8 MB open and 254.0 MB in tray (limits: 340/270 MB), with median CPU at 0.0%. Open-state p95 memory was 405.5 MB during startup settling. These measurements do not establish visible-window, active-engine, or long-running resource use.

The Windows installer is unsigned.
